01  /  Understanding

A medical amenity, not a clinic website.

Moray is a mixed-use commercial state — art, people, nature, architecture. The medical app is how that community reaches care without leaving the project. We read the brief as a resident amenity: simple, branded, and built to grow with every new doctor, specialty, and clinic you add.

Main Marks asked for a dedicated application where residents find doctors and specialties, open a full profile, see working hours, book a visit, cancel or reschedule, and receive confirmation and reminders — with clinics, departments, and services in the same place.

The platform must include iOS and Android, a web admin to run doctors, specialties, schedules, and appointments, and it must be fully branded and owned by the Moray Project. Scalability is not a later phase. It is a requirement from day one.

Bold

A product that looks like Moray — black, copper, cyan — not a generic healthcare template.

Transparent

Availability is real. A slot that is booked is gone. Admin and resident always see the same truth.

To the point

Find a doctor. Book a time. Get a reminder. No extra friction for a resident who simply needs care.

Owned

Source code, stores, and data belong to Moray. NixAI builds and hands over — we do not lock you in.

05  /  Architecture

The stack you asked for. Engineered to last.

React Native, Node.js, MongoDB, Next.js — specified because they let one team ship iOS, Android, and admin against a single API, then add clinics without rewriting the product.

Mobile — React Native

  • One codebase for iOS and Android, native store binaries
  • Navigation: home, directory, profile, booking, my visits, account
  • Push via APNs and FCM, permissioned and quiet when declined
  • Offline-tolerant profile cache; booking always confirmed online

API — Node.js + MongoDB

  • REST (or REST + selected RPC) for app and admin
  • Collections: users, doctors, specialties, clinics, schedules, appointments, notifications
  • Slot reservation with conflict checks — no double booking
  • Indexes designed for name and specialty search as the catalog grows

Admin — Next.js

  • Server-rendered dashboard, role-aware routes
  • CRUD for doctors, specialties, clinics, hours, and appointments
  • Operational views: today, this week, no-show and cancellation rates
  • Audit of who changed a schedule or moved a visit

Brand, hosting & ownership

  • Moray CI tokens in both apps — no generic medical teal
  • Staging and production environments under your accounts
  • Repositories, keys, and store listings in Main Marks / Moray control
  • 30 days of hypercare after store approval
