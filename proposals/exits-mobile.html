01 — Executive Summary

Why Exits Needs Mobile

The acquisition and investment market moves fast. Sellers tracking deal progress and buyers discovering opportunities shouldn't be tied to a desktop. A native-quality mobile app puts the full Exits platform in users' hands — accelerating deal flow, increasing engagement, and widening the platform's reach to mobile-first markets.

React Native — The Smart Choice
Exits already runs on React.js. Using React Native means sharing business logic, API calls, and state management with the existing web frontend — reducing development time by an estimated 35–40% compared to building two native apps, while delivering near-native performance on both iOS and Android.

05 — Technology Stack

Built to Extend What Exists

The tech choices are deliberate — everything maps to Exits' current web stack, minimising new infrastructure and maximising code sharing.

Shares component logic, API service layer, and state management with the existing React.js web app. Single codebase compiles to genuine native iOS and Android binaries. Expo Go enables over-the-air (OTA) updates without App Store resubmission for non-native changes.
